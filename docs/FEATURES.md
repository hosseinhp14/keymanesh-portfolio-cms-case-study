# Feature map

## Client-specific work highlighted in this repository

- Reusable multi-column content composition
- Responsive portrait / fullscreen media sections
- Mixed uploaded-media and external-video carousel
- Reel layout with independent desktop/mobile media sources
- CMS-managed page/post visual styling
- Custom Lexical font color/family/size controls
- Custom announcement bar and branded admin experience
- Newsletter submission integration pattern
- Client-specific frontend navigation and visual presentation

## Framework/template capabilities integrated into the production project

These are important parts of the final product, but they should not be represented as features implemented from scratch:

- Payload authentication and admin shell
- Drafts and version history
- Core live-preview support
- SEO plugin
- Redirects plugin
- Search plugin
- Form Builder plugin
- Nested Docs plugin

The project value is in turning that foundation into a client-specific production system and extending it where the default template was insufficient.
