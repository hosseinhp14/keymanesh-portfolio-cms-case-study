# Code sample notes

The files in `src-examples/` are derived from the production implementation and were intentionally changed before publication.

Changes made for the public case study include:

1. Removing client-specific names, IDs, endpoints and deployment paths.
2. Replacing production environment-variable names where a dedicated variable is clearer.
3. Tightening a few types and accessibility details so the examples represent the intended implementation rather than historical production workarounds.
4. Omitting framework boilerplate and template files that do not demonstrate project-specific engineering.
5. Removing database/data-layer content entirely.

Because these are review excerpts, import paths illustrate the production architecture but the directory is not presented as a standalone application.
